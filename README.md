Prueba del detalle oculto: se detuvo el servicio de SQL Server y se solicitó el listado de pedidos. El cliente recibió únicamente el mensaje “Error interno del servidor.”, mientras que el detalle real del problema de conexión quedó registrado en logs/errores.log. Esto es correcto porque los detalles técnicos del servidor no deben mostrarse al usuario final. El sistema informa un mensaje general y conserva el error completo en el registro para que pueda ser revisado por el desarrollador.
